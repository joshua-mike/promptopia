# Promptopia

Welcome to **Promptopia**, a modern web application that leverages AI to generate stunning images based on user-provided text prompts. Built with **Next.js** and integrated with the **Replicate API**, Promptopia showcases my passion for emerging technologies, combining full-stack development with AI-driven innovation. This project demonstrates my ability to architect scalable web applications, integrate third-party APIs, and deliver engaging user experiences.

## 🎯 Project Overview

Promptopia allows users to input descriptive text prompts through a sleek modal interface, which are sent to the Replicate API to generate high-quality, AI-crafted images. The application is designed for performance and usability, utilizing Next.js’s server-side rendering and static site generation for a fast, responsive experience. This project reflects my expertise in modern web development and my exploration of AI technologies, complementing my 8+ years of experience as a Senior Software Developer specializing in .NET/C# and secure systems.

## ✨ Features

- **AI-Powered Image Generation**: Users input text prompts to create unique images via the Replicate API.
- **Interactive Modal Interface**: A clean, user-friendly modal for entering prompts and viewing results.
- **Responsive Design**: Optimized for desktop and mobile devices using Tailwind CSS.
- **Scalable Architecture**: Leverages Next.js for server-side rendering and API routes for seamless backend integration.
- **Secure API Handling**: Implements environment variables and secure API key management for Replicate API calls.

## 🛠 Tech Stack

- **Frontend**: Next.js (React), Tailwind CSS
- **Backend**: Next.js API Routes
- **AI Integration**: Replicate API for image generation
- **Tools**: Vercel (deployment), Git, VS Code
- **Languages**: JavaScript, TypeScript, HTML, CSS

## 🚀 Getting Started

Follow these steps to set up and run Promptopia locally.

### Prerequisites

- Node.js (v16 or higher)
- A Replicate API key (sign up at [replicate.com](https://replicate.com))

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/joshua-mike/promptopia.git
   cd promptopia
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Set Up Environment Variables**:
   Create a `.env.local` file in the root directory and add your Replicate API key:
   ```env
   REPLICATE_API_TOKEN=your_replicate_api_key
   ```

4. **Run the Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.

### Deployment

Deploy Promptopia to Vercel for free:
1. Push your code to a GitHub repository.
2. Connect the repository to Vercel via the [Vercel Dashboard](https://vercel.com).
3. Add your `REPLICATE_API_TOKEN` to Vercel’s environment variables.
4. Deploy and access your live app!

## 📖 Usage

1. **Open the App**: Navigate to the deployed site or local server (e.g., http://localhost:3000).
2. **Enter a Prompt**: Click the “Generate Image” button to open the modal, then input a descriptive text prompt (e.g., “A futuristic city at sunset”).
3. **View Results**: Submit the prompt to see the AI-generated image displayed on the page.
4. **Experiment**: Try different prompts to explore the Replicate API’s capabilities!
